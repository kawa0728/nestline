# Nestline

Markdown と数式を扱える、ブラウザ内保存型のアウトライナーです。データはブラウザの IndexedDB に保存され、アカウントや同期サーバーは使いません。

## 起動

```powershell
npm install
npm run dev
```

表示されたローカル URL（通常は `http://localhost:5173`）をブラウザで開きます。

本番用ビルドを確認する場合は、次を実行します。

```powershell
npm run build
npm run preview
```

通常は `http://localhost:4173` が開きます。IndexedDB を安定して利用するため、`dist/index.html` を直接開くのではなくプレビューサーバーを使ってください。

## 基本操作

- ノードをクリックすると生テキストで編集します。フォーカスが外れると Markdown と数式を描画します。
- Enter で同じ階層にノードを追加します。空ノードでは逆インデントします。
- Tab / Shift+Tab でインデント / 逆インデントします。
- Shift+Enter でノード内を改行します。
- 空ノードで Backspace を押すと、ノードと子を削除して前の可視ノードへ移動します。
- ↑ / ↓ で可視ノード間を移動します。
- Ctrl+↑ / ↓ または Alt+↑ / ↓ でノードを子ごと並べ替えます。ドラッグでも移動できます。
- ノード横のトグル、または Ctrl+Shift+Space で折りたたみ / 展開します。上部操作から全展開・全折りたたみ・深さ指定もできます。
- ノードのズームボタン、または Alt+→ で部分木にズームします。パンくず、または Alt+← で上位階層へ戻ります。
- ノードの複製・子ごと削除は各ノードの操作ボタンから行い、削除は Undo で戻せます。

## 検索とタグ

上部の検索欄で入力すると、ヒットしたノードと祖先だけを表示します。ズーム中はズーム範囲内を検索します。`#タグ` をクリックすると同じタグのノードに絞り込みます。Esc またはクリアボタンで解除できます。絞り込みは表示上の射影で、折りたたみ状態は変更しません。

## Markdown と数式

太字（`**太字**`）、斜体（`*斜体*` / `_斜体_`）、コード（`` `code` ``）、リンク（`[文字](URL)`）、取り消し線（`~~文字~~`）、タグ（`#tag`）に対応します。インライン数式は `$...$`、ブロック数式はノード全体を `$$...$$` で囲みます。ノード全体を三連バッククォートで囲むとコードノードになります。描画時の Markdown はサニタイズします。

## 入出力

上部の「入出力」メニューから形式と範囲を選びます。ズーム中は文書全体またはズーム中の部分木を書き出せます。

| 形式 | インポート | エクスポート |
| --- | --- | --- |
| Markdown | 見出しと字下げ箇条書き | 入れ子箇条書き |
| OPML 2.0 | `outline` の入れ子、`text` と `_note` | OPML 2.0 |
| JSON | Nestline 文書モデルを検証して読み込み | 文書モデル |
| LaTeX | — | `layer` / `itemize` の2形式 |

インポートでは既存文書の置き換え（既定。実行前に確認）または新規ノードとしての追加を選べます。Markdown と OPML は UTF-8 テキストとして読み込みます。LaTeX は `ltjsarticle` と HaranoAji フォントを使うため、PDF化には LuaLaTeX と同フォントが必要です。

## キーボードショートカット

| キー | 操作 |
| --- | --- |
| Enter | 兄弟ノードを追加。空ノードでは逆インデント |
| Shift+Enter | ノード内改行 |
| Tab / Shift+Tab | インデント / 逆インデント |
| 空ノードで Backspace | ノードと子を削除し、前の可視ノードへ移動 |
| ↑ / ↓ | 可視ノード間の移動 |
| Ctrl+↑ / ↓ または Alt+↑ / ↓ | 子ごと並べ替え |
| Ctrl+Shift+Space | フォーカス中のノードを折りたたみ / 展開 |
| Alt+→ / Alt+← | ズーム / 親階層に戻る |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z または Ctrl+Y | Redo |
| Ctrl+F | 検索欄へ移動 |
| Esc | 検索・タグフィルタを解除 |
| Enter または F2 | フォーカス中の表示ノードを編集 |
| ? | ショートカットヘルプを開閉 |

画面下部の「ショートカット」ボタンでも一覧を開けます。

## 保存とバックアップ

文書はブラウザの IndexedDB（データベース `nestline`）へ自動保存されます。保存データはブラウザ・プロファイル・オリジンごとに分かれます。ブラウザのサイトデータ消去やプロファイル削除で失われるため、入出力メニューから JSON を定期的にエクスポートして別の場所に保管してください。復元時は JSON をインポートします。

保存エラーが表示された場合は、画面の「JSONバックアップを保存」を押して、現在メモリ上にある文書を退避してください。
